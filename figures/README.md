# Figures

Representative generated outputs from completed experiments live here.

Recommended convention:

- create one subdirectory per experiment
- keep filenames stable and descriptive
- keep one especially strong figure suitable for the top of `README.md`
- commit representative figures, not every intermediate artifact

Experiment 4's complete review evidence is intentionally stored as a
deterministic five-file class-grouped montage series. Every frozen image and
candidate cutoff remains visible.
